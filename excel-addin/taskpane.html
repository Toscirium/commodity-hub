Commodity Hub

Commodity data as Excel formulas.

API key

Create one at app.commodity-hub.eu/exports. Free tier: 1 key, 50 requests/day, no card.

Stored in Excel's per-user add-in storage on this device only — never written into the workbook, so sharing the file does not share your key.

Formulas

Type =CH. in a cell to see these with inline help.

=CH.PRICE("Corn Futures")
Current price, in the exchange's own quote.
=CH.PRICE_IN("Corn Futures","USD/t")
Price restated per tonne. CBOT grains quote in cents per bushel, so this is not a cosmetic change.
=CH.BASIS("Corn Futures",195,"EUR/t",0.92)
Your cash price minus futures, both in the same unit.
=CH.CONVERT("Corn Futures",550.75,"EUR/t",0.92)
Restate a price you already have. No API call, no quota used.
=CH.COT("Corn Futures","net_position")
Latest CFTC positioning. Also CH.COT_DATE.
=CH.HISTORY("Corn Futures","6m")
Spills a date/close range. One call, many rows.
=CH.LOTS_FOR("Corn Futures",1000,"tonne")
Lots needed to hedge that quantity. No API call.
=CH.CONTRACT_TONNES("Corn Futures")
Tonnes per contract — 127.01 for corn, 136.08 for wheat.

Quota

Responses are cached for 60 seconds, and identical simultaneous calls share one request — so filling a column doesn't multiply your usage. CONVERT, LOTS_FOR, LOTS_TO_QTY and CONTRACT_TONNES are pure maths and never call the API at all.
