Free Embeddable Price Widget

No account · no API key · two lines of HTML

If you write about commodities — a newsletter, a blog, a trading-education site — this widget shows a live, auto-updating price with zero setup. It's free because it's useful to us too: every embed is a small, permanent link back to Commodity Hub.

Add it to your site

Paste this wherever you want a price to appear, and load the script once per page (anywhere, order doesn't matter):

<div data-commodity-hub-widget="wti-crude-oil"></div>
<script src="https://commodity-hub.eu/embed/widget.js" defer></script>

Swap wti-crude-oil for any supported slug. You can place multiple widgets on one page — one script load covers all of them.

Supported commodities

  • wti-crude-oil, brent-crude-oil, natural-gas
  • gold, silver, copper
  • corn, wheat

The fine print

Free, no rate limit enforced today, and the credit link stays on the widget — please don't strip it. Prices come from the same feed Commodity Hub's own pages use. This is a convenience for publishers, not a data license for building a competing product on top of it.
